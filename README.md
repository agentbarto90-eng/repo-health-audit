# Repo Health Audit

A read-only audit of a public GitHub repository. Scores five dimensions —
documentation, testing, CI/CD, issue triage and maintenance — and emits a
prioritised report plus ready-to-file issue drafts.

Live offer page: https://agentbarto90-eng.github.io/repo-health-audit/

## Usage

Try it without installing anything (browser, no sign-up):

https://agentbarto90-eng.github.io/repo-health-audit/

Or run the scanner yourself:

```bash
export GITHUB_TOKEN=...          # or use the gh CLI
python3 repo_audit.py owner/repo --out report.md --issues issues.md
python3 repo_audit.py owner/repo --json
```

This tool is read-only. It never writes to the audited repository and only
reads data any visitor could read through the public GitHub API.

## Free scan vs full report

The free scan is a lead magnet, not the product:

- **Free scan** (`repo_audit.py --teaser`): overall score, the five dimension
  scores, and the titles of the top three findings. This is what the automated
  workflow posts back on a request issue.
- **Full report** (£29): every finding written up and ordered, ready-to-file
  issue drafts with labels, and a fix pack of files you can review and commit.

Keeping the boundary in the tool stops the free channel from giving the paid
report away.

## Get a free scan

Open a request at
https://github.com/agentbarto90-eng/repo-health-audit/issues/new?template=audit-request.yml
and the public scan runs against the repository you name. The offer page form
composes the same request as a pre-filled issue, so no data is collected by the
page itself.

An issue carrying the `audit-request` label starts the
[`Free repo health audit`](.github/workflows/audit-request.yml) workflow, which
runs `repo_audit.py --teaser` against the repository named in the issue and
posts the free scan back as a reply. It is read-only and uses only the
workflow's built-in token, so no credentials are stored here.

For the full £29 report, open an issue at
https://github.com/agentbarto90-eng/repo-health-audit/issues/new
and say you want the full audit. It is delivered as a written report plus the
fix pack.

## Files

- `index.html` — the offer / landing page (single self-contained file)
- `repo_audit.py` — the audit tool (`--teaser` for the free scan)
- `fix_pack.py` — turns a full audit dump into the £29 fix pack
- `run_audit_request.py` — resolves a request issue to a repository and runs the free scan
- `sample-report.md` — example full report
- `sample-issues.md` — example ready-to-file issue checklist
- `test_repo_audit.py` — unit tests for the audit logic and the free/paid boundary
  (`python3 -m unittest -v test_repo_audit`)

### Producing the paid deliverable

```bash
python3 repo_audit.py owner/repo --out report.md --issues issues.md --dump-json audit.json
mkdir -p out
python3 fix_pack.py owner/repo --from-json audit.json \
  --outdir out/tree --index out/FIX-PACK.md \
  --pack out/fix-pack.md --patch out/fix-pack.patch
```

The patch applies with `git apply`; the tree contains the suggested files.

Generated by an AI agent (OpenHands) on behalf of the user.
